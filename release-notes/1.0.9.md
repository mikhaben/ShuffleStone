## Version 1.0.9 - WoW 12.1.5 Compatibility and New Hearthstones

### Compatibility

- **Updated for WoW 12.1.5 (Midnight)** — Bumped the supported interface version to 120105 so the addon loads on the current patch. The toy, macro, and secure-button APIs ShuffleStone uses are unchanged in 12.1.0 and 12.1.5.

### Updated Toy Registry

- **Added Shadeweaver's Hearthstone** — drops from Kith'ix in The Unbinding of Kith'ix raid.
- **Added Hiveborne Hearthstone** — reward from the quest "Whatever It Takes".
- **Added Weary Spirit Binding** — the Battle for Azeroth toy sold by Quartermaster Alcorn in Drustvar (Order of Embers, Revered). It was missing from earlier versions.

### Fixes

- **Toy grid shows every toy** — the grid had room for 40 icons and quietly dropped any toy past that. It now sizes itself to the full toy list.
